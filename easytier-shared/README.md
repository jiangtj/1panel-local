## 产品介绍

**EasyTier Shared** 是 EasyTier 的共享节点（公共中继服务器）：它自己不加入任何虚拟网络，只为其他网络提供中继与节点发现能力，让没有公网 IP 的节点也能组网。本应用以 Docker 方式运行 `easytier-core`，并把官方文档中「搭建公共服务器」的两种形态做成可切换的配置项。

本应用提供 `latest`（上游稳定发布）与 `unstable`（滚动构建）两个版本。

## 主要功能

- **数据转发开关**：开启时为白名单内的虚拟网络转发流量（即官方文档的公共共享节点）；关闭时只帮助其他节点建立 P2P 连接，不转发任何数据包。
- **转发白名单**：按网络名（`--network-name`）通配符过滤，如 `home* office-*`；填 `*` 或留空表示对所有网络开放转发。
- **TCP / UDP 双协议监听**：同一个宿主机端口同时映射到容器 `11010/tcp` 与 `11010/udp`。
- **长跑友好**：`nofile` 上限提升到 65536，避免公共节点连接数多时 fd 耗尽；镜像自带基于 `easytier-cli` 的健康检查。

## 参数说明

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| 监听端口 | `31010` | 宿主机 TCP + UDP 端口，映射到容器 `11010`。其他节点用 `udp://服务器IP:端口` 或 `tcp://服务器IP:端口` 连接，防火墙需同时放行 TCP 与 UDP |
| 数据转发 | 开启 | 开启 = 为白名单内的网络转发数据；关闭 = 仅帮助下线节点建立 P2P 链路 |
| 转发白名单 | `*` | 仅在开启数据转发时生效；空格分隔的网络名通配符，`*` 或留空表示全部网络 |

安装后实际执行的命令与配置项的对应关系：

| 数据转发 | 转发白名单 | 实际命令 |
| --- | --- | --- |
| 开启 | `*` | `easytier-core --relay-network-whitelist "*"`（等价于官方「纯公共服务器」，即不带参数启动） |
| 开启 | `home* office` | `easytier-core --relay-network-whitelist "home* office"` |
| 关闭 | 忽略 | `easytier-core --relay-network-whitelist --relay-all-peer-rpc` |

## 使用说明

1. 安装本应用，按需选择是否开启数据转发，并填写转发白名单。
2. 在服务器/云厂商安全组与系统防火墙中放行「监听端口」的 **TCP 与 UDP**。
3. 其他节点接入时，把对端地址指向本节点，例如 `udp://服务器公网IP:31010` 或 `tcp://服务器公网IP:31010`；Web 控制台可在「对端地址」中直接填写该地址。

## 注意事项

- 共享节点本身不需要网络名与网络密钥。若给它加上 `--network-name` / `--network-secret` 并启用私有模式，它就只为那一个网络服务，不再对公众开放。
- 公共节点常被扫描，日志里会出现大量 `wait handshake timeout` 记录，可按官方文档用 fail2ban 限制来源 IP。
- 应用只映射了 `11010`（TCP/UDP）。默认监听里还包含 `11011`（wg/ws）与 `11012`（wss），如需让客户端通过 WebSocket 接入，需自行在 compose 中补充端口映射。
- 该节点转发的是应用层流量，不依赖内核转发，因此未使用 `NET_ADMIN`、`/dev/net/tun` 与转发 sysctl。
