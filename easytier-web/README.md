## 产品介绍

**EasyTier Web** 是 EasyTier 的 Web 控制台，运行时采用前后端一体的 easytier-web-embed，可自建用于集中管理 EasyTier 节点。

## 主要功能

- **节点集中管理**：在网页中注册账户、查看节点状态、配置节点参数并查看节点日志。
- **配置下发**：通过 UDP 端口为 easytier-core 节点下发配置，便于统一管理多个节点。
- **数据持久化**：账户与配置数据保存在本地 data 目录，容器重建后仍可保留。
- **反向代理支持**：可填写域名或反向代理访问地址，留空则自动使用服务器 IP 与 Web 端口。
