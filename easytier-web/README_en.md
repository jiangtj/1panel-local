## Introduction

**EasyTier Web** is the EasyTier web console, running the front-end and back-end combined easytier-web-embed binary for self-hosted, centralized EasyTier node management.

## Features

- **Centralized Node Management**: Register accounts, view node status, configure node parameters and read logs in the browser.
- **Configuration Delivery**: Deliver configuration to easytier-core nodes over a UDP port for unified management of multiple nodes.
- **Persistent Data**: Account and configuration data are stored in the local data directory and survive container recreation.
- **Reverse Proxy Support**: Set a domain or reverse proxy URL, or leave it empty to use the server IP and web port automatically.
