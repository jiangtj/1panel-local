## 产品介绍

**magpie** 是一个本地模型网关：它同时支持 OpenAI、Anthropic 和 Gemini 三种 API 并互相转换，让任何编码 Agent 都能使用任意厂商的模型。本应用以 Docker 方式运行该网关和 Web 界面，供其他机器上的 Agent 使用。

## 主要功能

- **多协议转换**：网关同时支持 OpenAI Chat/Responses、Anthropic Messages 和 Gemini API，并在它们之间自动转换，流式输出、工具调用和推理过程一并支持。
- **统一的模型选择**：在 Web 界面中集中管理供应商与模型，按 provider/model 或路由组把模型分配给 Claude Code、Codex、Gemini CLI、OpenCode 等 Agent。
- **路由组与配额**：把多个模型或账号组合为一个路由组，额度用完时自动切换到下一个，并可在用量页查看余额、令牌与花费。
- **网关密钥**：为容器外的每台机器生成独立网关密钥并设置用量上限，容器外的请求必须携带启用的密钥，否则返回 401。
- **Web 界面**：在浏览器中完成供应商添加、订阅登录、路由配置、用量查看与插件管理，Docker 下默认为网关模式。

## 使用说明

1. 安装后从容器日志获取带密钥的 Web 界面地址（`docker logs <容器名>` 会打印 `http://<服务器地址>:<网页端口>/?k=<Web 密钥>`）
2. 在「供应商」里添加 API Key 或登录订阅，再为每个 Agent 选择模型
3. 容器外的每台机器都要在「网关 → 网关密钥」生成一个密钥，并把 Agent 的 Base URL 指向 `http://<服务器地址>:<网关端口>`：OpenAI 客户端用 `/v1`，Anthropic / Gemini 客户端用根地址

## 数据目录

| 目录 | 内容 |
| --- | --- |
| `./config` | 供应商、密钥、登录、插件和使用量，magpie 的全部状态都在这里 |

备份时整体备份 `./config` 即可。镜像以非 root 用户（uid 65532）运行，安装时会把该目录所有者改为 `65532:65532`。

> Web 界面本身没有 HTTPS，请放在带 TLS 的反向代理后面，或通过 VPN / SSH 隧道访问；网关端口跨互联网访问建议使用 VPN，不要直接对公网开放。
